<h1>Movie Recommendation System</h1>

<p>This project is a Movie Recommendation System built using Machine Learning. The goal of this model is to recommend movies to users based on their previous ratings and preferences.</p>

<h2>📂 Project Structure</h2>

<h2>🔍 Dataset</h2>

<p>The dataset used for this project comes from the MovieLens dataset, which contains user ratings for various movies. This dataset is commonly used in recommendation system projects.</p>

<h2>🔨 Project Features</h2>

<ul>
  <li>Feature 1: Collaborative filtering using matrix factorization techniques (e.g., SVD).</li>
  <li>Feature 2: Content-based filtering using movie metadata such as genres and directors.</li>
  <li>Feature 3: Hybrid recommendation system combining collaborative and content-based filtering.</li>
</ul>

<h2>✔️ Technologies Used</h2>

<ul>
  <li>Python</li>
  <li>Pandas</li>
  <li>Scikit-learn</li>
  <li>SVD (Singular Value Decomposition)</li>
  <li>MovieLens dataset</li>
</ul>

<h2>📊 Model Evaluation</h2>

<p>The model is evaluated using metrics such as Root Mean Squared Error (RMSE) and Mean Absolute Error (MAE) to measure prediction accuracy on unseen data.</p>
